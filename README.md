# AI-Driven Software Testing & Code Refactoring

A comprehensive test generation system that uses both **Pynguin** (automated test generation) and **Ollama** (LLM-based test generation) to create and execute test cases for Python code.

## Features

- 🔄 **Dual Test Generation Methods**:
  - **Pynguin**: Automated test generation using search-based algorithms
  - **Ollama**: LLM-powered test generation using StarCoder model
  
- 📊 **Comprehensive Metrics**:
  - Test coverage
  - Pass/fail rates
  - Generation and execution times
  - Detailed test reports

- 🎯 **Property-Based Testing**: Automatic generation of Hypothesis-based property tests

- 📈 **Detailed Reporting**: JSON reports and terminal summaries

## Installation

1. Install Python dependencies:
```bash
pip install -r requirements.txt
```

2. Install Ollama (if not already installed):
   - Visit: https://ollama.ai
   - Download and install Ollama
   - Pull the StarCoder model:
   ```bash
   ollama pull starcoder
   ```

## Usage

### Quick Start

Run all test generation methods and get a comprehensive report:

```bash
python run_all_tests.py my_code.py
```

This will:
1. Generate tests using Ollama
2. Generate tests using Pynguin
3. Create property-based tests
4. Run all generated tests
5. Generate a comprehensive report

### Individual Methods

#### Generate tests with Ollama only:
```bash
python generate_test.py my_code.py
```

#### Generate tests with Pynguin only:
```bash
python generate_and_run_tests.py my_code.py
```

### Output Directory

Specify a custom output directory:

```bash
python run_all_tests.py my_code.py ./custom_test_dir
```

## Test Files Location

All generated test files are saved in the `generated_tests/` directory (or your specified directory):

- `test_<module>_ollama.py` - Tests generated by Ollama
- `test_<module>.py` - Tests generated by Pynguin
- `test_properties.py` - Property-based tests (Hypothesis)

## Reports

### Terminal Report

The system displays a comprehensive summary in the terminal including:
- Generation and execution times for each method
- Test counts (total, passed, failed, skipped)
- Pass rates
- Code coverage
- Test file locations

### JSON Report

A detailed JSON report is saved to `generated_tests/test_report.json` with:
- Timestamp
- Module information
- Detailed metrics for each method
- Test file paths
- Error messages (if any)

## Metrics Tracked

- **Generation Time**: Time taken to generate tests
- **Execution Time**: Time taken to run all tests
- **Test Count**: Total number of tests generated
- **Pass Rate**: Percentage of tests that pass
- **Coverage**: Code coverage percentage (when available)
- **Success Rate**: Whether test generation succeeded

## Troubleshooting

### Ollama not found
If you see "ollama command not found":
1. Install Ollama from https://ollama.ai
2. Ensure it's in your PATH
3. Pull the model: `ollama pull starcoder`

### Pynguin timeout
If Pynguin times out:
- The system will continue with partially generated tests
- Adjust timeout in `generate_and_run_tests.py` if needed

### No tests generated
- Check that your code file exists and is readable
- Verify that functions are properly defined
- Check error messages in the terminal output
